# 🐈 Bastet Agent Sync — 使い方と計画

[繁體中文](../zh-Hant/guide.md) · [简体中文](../zh-Hans/guide.md) · [English](../en/guide.md) · [日本語](../ja/guide.md) · [한국어](../ko/guide.md)

エージェントと会話を、別のコンピューターでも。

> スナップショットのコアを実装しました。デスクトップの **隔離テストを実行** を押すと、2つの一時レプリカと共有フォルダーでサンプルテキストを転送し、2つの分岐の保持、重複転送の防止、再起動後の復元を確認します。選択したエージェントや Drive フォルダーにはアクセスしません。

## 予定している設定手順

1. 言語と端末名を選びます。
2. Claude、Claude Code、Codex、Google Agy CLI、Grok Build CLI、Pi Agent を検出して選択します。パスも指定できます。
3. Google Drive に接続し、共有フォルダーを選択または作成します。Linux では今後実装する API 接続を使います。
4. 双方向、アップロードのみ、ダウンロードのみと、手動、間隔指定、ほぼリアルタイムの頻度を選び、設定後に開始します。
5. 有効にするとウィンドウをトレイに格納できます。トレイから一時停止・再開もできます。

## 現在の基盤機能

会話内容を読まずに候補ディレクトリを検出し、ローカルフォルダーを選択して設定を保存します。クラウド接続とアダプターの検証まではエージェント同期の開始ボタンを無効にします。ブラウザープレビューではネイティブ機能を使えません。

## 会話の再開

ネイティブ復元には検証済みのアダプターが必要です。コンテキストを渡す方式は新しい会話として明示します。エクスポート可能な添付ファイル、ツール結果、プロジェクトパスを保持します。同時変更は分岐として保持し、認証情報は端末内に残します。

## ロードマップ

M0：リポジトリ、計画、5言語、猫のアイコン。M1：デスクトップ、検出、設定、トレイ。M2：スナップショット、競合、ローカル転送。M3：Google Drive と暗号化。M4：エージェントのネイティブ復元。M5：スケジュールと3 OS 向け配布。

## 開発方法

Node.js、Rust、Tauri の OS 別前提条件をインストールし、リポジトリのルートで次のコマンドを実行します。

```sh
npm ci
npm test
npm run build
cargo test --manifest-path src-tauri/Cargo.toml --locked
npm run tauri dev
```

## 検証と制限

Windows／Linux のビルドとトレイの動作は検証が必要です。M1 はクラウドへのログイン、アップロード、会話のインポートを行いません。会話履歴の移動は実行中のプロセスを移動しません。

## M2：隔離コアテスト

スナップショットのコアを実装しました。デスクトップの **隔離テストを実行** を押すと、2つの一時レプリカと共有フォルダーでサンプルテキストを転送し、2つの分岐の保持、重複転送の防止、再起動後の復元を確認します。選択したエージェントや Drive フォルダーにはアクセスしません。

エージェントのネイティブ同期ではありません。Google Drive ログイン、暗号化、会話のネイティブ復元とスケジュールは未実装です。v1 は準備済みテキストのみを扱い、全バージョンを保持し、削除を伝播しません。

## 🐈 M3 クラウドプレビュー

OAuth と資格情報ストアのコード、暗号化 Drive API、サンプルデータの暗号化・復元確認を実装しました。標準ビルドには OAuth クライアントがなく、ログインは無効です。ローカル HTTP テストは Google や実機 2 台での検証ではありません。暗号化キューは隔離された 2 つのレプリカを交換し、分岐と再試行 ID を保持します。スペース・鍵のウィザードは実装済みです（下記）。Picker と GUI の同期制御は未完了です。

[Technical contract / 技術文件](../../CLOUD_SECURITY.md)

## 🐈 設定ウィザード・再開・手動設定

Drive 設定はログイン設定、Google 認証、フォルダー、暗号化と復元、最終確認の 5 段階です。完了した手順とモードを自動保存し、再起動後に続行できます。やり直しでは古い記録を保存し、Drive データや鍵は削除しません。手動設定では全項目を表示し、同じ検証を行います。組み込みクライアントがない場合はデスクトップ OAuth JSON をインポートできます。フォルダー ID・リンクを直接入力でき、新規スペースでは復元ファイルを保存し、別のコンピューターのスペースにはその復元ファイルをインポートします。設定完了は Agent 同期の開始ではありません。

[Setup contract / 設定文件](../../SETUP_WIZARD.md)

## 🐈 アカウント確認と ChatGPT 統合版

ウィザードに接続中または保存済みの Google アカウントを表示し、別アカウントでの再開を拒否します。ローカルのログインを削除して元のアカウントで再接続するか、設定を最初から開始してください。旧進捗も読み込め、明示的な再接続でアカウントを登録します。

統合版 ChatGPT デスクトップのローカル Codex／Worktree をアダプター対象に含めます。ローカル ChatGPT Work は形式と再開方法の検証が必要です。通常の ChatGPT チャットとクラウドタスクは別途連携を調査します。別のコンピューターでのネイティブ復元は未検証です。

[OpenAI documentation](https://learn.chatgpt.com/docs/environments/modes) · [ChatGPT / Codex](https://learn.chatgpt.com/docs/use-chatgpt)

## 🐈 Google 認証待ちのキャンセル

接続時にブラウザー認証待ちをキャンセルして、保存済みの進捗を保持したまま再接続できます。ブラウザーを閉じるだけでは三分間のタイムアウトを待ちます。トークン交換とアカウント確認の完了は待つ必要があり、キャンセルできない段階は画面に表示します。

## 🐈 Agent Memory OS

七番目のソースとして追加しました。記憶ディレクトリまたは AGENT_MEMORY_HOME を指定し、公式 AMOS CLI で出力した JSONL を確認できます。バージョン 1–3、最大 1 MiB に対応します。内容を保持するプレビューであり、自動エクスポート、Drive 公開、稼働中 DB へのインポートは未対応です。私的な記憶を含む可能性があり、削除・組織権限の適用には確認が必要です。

[Adapter contract](../../AGENT_MEMORY_OS.md)

ブラウザー起動前の失敗は、設定の読み取り、保存済みログイン、ブラウザー起動に分けて表示します。開発版更新後は旧プロセスを終了して再起動し、設定を読めない場合は JSON を再インポートしてください。資格情報ストアから読み戻せた場合のみステップ 1 を完了します。
